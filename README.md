# 笑笑桌宠

一个轻巧、透明、会在桌面上晃来晃去的笑笑桌宠。

**谁不想急头白脸地在自己桌面养一只笑笑呢？**

这个项目使用 `Electron + React + PixiJS` 实现，把笑笑放进一个透明无边框窗口里。她会待在桌面上陪你写代码、发呆、摸鱼，也会在你点击她的时候蹦一下、冒出一句小台词。

## 有什么好玩

- 透明无边框窗口，看起来就像笑笑真的站在桌面上。
- 可以用鼠标拖来拖去，把笑笑摆到你喜欢的位置。
- 点击笑笑会触发弹跳和气泡台词。
- 待机时会呼吸、漂浮、轻轻摇晃，偶尔点头、伸懒腰或自己说句话。
- 右键菜单可以隐藏、重置位置、放大、缩小、切换置顶。
- 托盘菜单可以快速显示、隐藏或退出。
- 位置、缩放和置顶状态会保存在本地，下次打开还能接着养。

## 项目结构

```text
assets/        桌宠图片、托盘图标和角色配置
src/main/      Electron 主进程，负责窗口、菜单、托盘和本地配置
src/preload/   主进程与页面之间的安全桥接
src/renderer/  React 页面、PixiJS 桌宠渲染和交互逻辑
src/shared/    主进程与渲染进程共用的类型
```

默认角色素材在 `assets/pets/xiaoxiao/` 中，`manifest.json` 里配置了角色名称、图片、气泡台词和待机动作。

## 本地运行

```bash
npm install
npm run dev
```

启动后，笑笑就会出现在桌面上。把她挪到顺眼的位置，然后开始你的桌面饲养生活。
